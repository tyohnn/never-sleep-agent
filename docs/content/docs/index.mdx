**never-sleep-agent**는 제품 파이프라인이 아니라 **밤새 운영 OS**다.

cron이 깨우면 → Slack inbox → Notion hub → (있으면) Oh My Docs 게이트 → 역할 작업 → Slack outbox.

이 핸드북이 문서 SSOT다. 채팅에만 남기지 말고, 결정·합의·새 논의를 여기(또는 Notion ops)에 써라.
