제네릭 프롬프트를 바로 붙이지 마라. **레포를 이해한 뒤** 맞춤 프롬프트를 Cursor Automations에 저장한다.

## 필수 입력

| 입력 | 어디 |
|---|---|
| Notion 루트 페이지 | `never-sleep.config.json` → `notion.rootPageUrl` |
| Base branch | `immutable.baseBranch` = `main` 또는 `dev` |
| Slack owner + channel | `slack.ownerUserIds`, `outboxChannelId` |
| 제품 레포 | Cursor + `AGENTS.md` |

## 순서

1. 스킬 설치 + MCP (Notion / Slack / Supabase / Vercel)
2. `node scripts/adopt.mjs --install-skills` (companion pack)
3. 레포의 `guides/onboarding.md` / `templates/onboarding-prompt.md`로 레포 이해
4. 맞춤 `AGENTS.md` + `docs/ops/automation-*.md` 작성
5. Notion 루트 아래 워크스페이스 구조 (`templates/notion-workspace-structure.md`)
6. Cursor Automations ×4에 **맞춤** 프롬프트 저장 + cron

상세 end-user 가이드는 레포 `guides/user-guide.md`.
