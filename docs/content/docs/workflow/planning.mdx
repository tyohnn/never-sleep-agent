제품 변경은 핸드북(이 SSOT)에 intent가 잡힌 뒤에만 간다.

1. PRD / story / ADR / plan을 카탈로그에 쓴다.
2. plan이 `ready`|`active`일 때만 구현 트랙을 연다.
3. worker는 구현을 서브에이전트에 넘기고, Notion Tasks/LEASE로 추적한다.
4. director가 STEER·Research·Goals를 보고 우선순위와 parallelTracks를 갱신한다.
