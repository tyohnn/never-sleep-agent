## Vision

사람은 자고, 에이전트는 일한다. 다만 **주인이 Slack에서 답한 조타(STEER)** 가 모든 에이전트 계획보다 우선한다.

never-sleep-agent는 Cursor Automations 네 역할(worker / director / researcher / auditor)을 한 레포에 붙이고, Notion을 ops hub로, Oh My Docs를 제품 핸드북 게이트로 쓴다.

## Principles

1. **cron = spawn only** — wake는 길어도 되고, 빈 손 exit는 금지.
2. **Helmsman first** — owner Slack → Notion `STEER` + Requests.
3. **Worker는 오케스트레이터** — 제품 코드는 Task 서브에이전트에게만.
4. **Ops는 Notion, 핸드북은 OMD(Supabase SSOT)** — 역할이 다르다.
5. **Base `main`|`dev` + green lease-safe PR auto-merge**.

## Not yet in scope

- Notion DB 완전 자동 프로비저닝 (v0)
- Oh My Docs 대체
