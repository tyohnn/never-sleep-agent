# Slack outbox report template

Post as a reply in the standing overnight thread (or new top-level post for a new night).

```text
*[REPO] wake · <MODE>*
Why: <one line>

*Changed*
• …
• …

*PR*
<url | none>

*Evidence*
• run-log: <Notion url>
• <screenshots / artifacts>

*Inbox*
• absorbed: <n> → Task links — or none

*Next*
• <nextHeavy one-liner>

*Blockers*
• <none | …>
```

Keep it scannable. Humans reply in-thread to steer the next wake.
